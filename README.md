# 基金智能监控雷达 PRO MAX V9.2

Streamlit 网页部署版，内置 **153只基金**。

## V9.2 更新
- 115只旧基金 + 用户新增基金，去重后共153只。
- 历史数据多通道：东方财富 `pingzhongdata` → 东方财富 F10 → 腾讯日K → 新浪日K → Yahoo。
- ETF 实时多通道：东方财富 → 腾讯 → 新浪。
- 开放式基金实时估值：天天基金 → 腾讯基金兜底。
- 并发从3路提升到8路；历史数据缓存24小时，实时数据缓存3–5分钟。
- 侧边栏增加“测试数据通道是否通畅”，可直接从 Streamlit 云端测试实际网络连通性。
- 保留严格买入逻辑：趋势 + MACD + RSI + 20/60日动量等多指标共振。
